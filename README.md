#Everything for the cars lives there.

New car: Make a new folder in stock named Make Model - Year - Price, like Toyota Camry - 2019 - 21000, and put the car’s photos inside.
Photos and price: Rename your best photo to cover.jpg and it becomes the main picture. To change the price, just rename the folder’s last number.
Extra details (the JSON file): Only if you want to show things like fuel, kilometres or colour, add a small text file called details.json inside that car’s folder. Copy the example from HOW TO ADD A CAR.txt and change the values.
Remove or finish: Delete the car’s folder to take it off the website, then refresh the page.
